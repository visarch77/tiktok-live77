# Nhạc nền riêng cho Phòng Tụng Kinh

Thả file nhạc thiền **không lời** (`.mp3`, `.m4a`, `.ogg`, `.wav`) vào thư mục này,
rồi vào trang quản lý → ⚙️ Cài đặt → 🔊 Âm thanh → **Nhạc nền** để chọn.

- Chỉ dùng nhạc bạn **có quyền phát trên livestream** (nhạc tự sáng tác, nhạc mua bản quyền,
  hoặc nhạc miễn phí bản quyền ghi rõ cho phép dùng thương mại/livestream). TikTok có thể tắt tiếng
  hoặc hạn chế buổi live dùng nhạc có bản quyền.
- Tên file nên ngắn, không dấu, ví dụ `thien-sang-som.mp3`.
- Nhạc được phát lặp lại, tự nhỏ đi khi có chuông và giọng đọc.
